Cài Đặt Harasocial Tool

Tài liệu hướng dẫn thiết lập tiện ích trên thiết bị iPad

👉 Lưu ý: Do hạn chế kỹ thuật của Apple, trình duyệt Google Chrome trên iPad không hỗ trợ cài đặt các extension mở rộng trực tiếp. Chúng ta sẽ sử dụng trình duyệt Orion Browser để thay thế (đây là trình duyệt tối ưu hỗ trợ đầy đủ API Chrome Extension trên iOS).

Tải file cài đặt về máy

Nhấp vào nút dưới đây để tải về tệp tin ZIP của tiện ích và chia sẻ lên iPad của bạn.

Tải file USER_TOOL.zip
1
Chuyển file ZIP sang iPad và lưu trữ
Gửi file USER_TOOL.zip vừa tải sang iPad của bạn (qua AirDrop, Drive, Zalo, Messenger, Mail...) sau đó thực hiện lưu tệp:
  • Mở ứng dụng Tệp (Files) trên iPad.
  • Lưu tệp zip này tại thư mục Trên iPad (On My iPad). Việc lưu trực tiếp trên thiết bị giúp Orion dễ dàng đọc tệp mà không gặp lỗi phân quyền của iCloud.
2
Cài đặt Orion Browser & Bật chế độ Extension
  • Tải trình duyệt Orion Browser từ App Store.
  • Mở Orion, chạm vào biểu tượng ba chấm (•••) -> Chọn Settings (Cài đặt).
  • Cuộn xuống dưới và kích hoạt mục Chrome or Firefox Extensions nếu chưa được bật.
3
Import tiện ích mở rộng vào Orion
  • Trở lại trình duyệt Orion, bấm vào Menu ba chấm (•••) -> Chọn Extensions.
  • Bấm nút Dấu cộng (+) ở thanh công cụ và chọn Install from API/File.
  • Tìm và chọn tệp USER_TOOL.zip đã lưu ở Bước 1.
4
Truy cập Harasocial để sử dụng
Truy cập trang Harasocial trên Orion và đăng nhập:
  • Bạn sẽ nhìn thấy thanh công cụ nổi tích hợp đầy đủ các tính năng kiểm tra phí ship, khuyến mãi, bảo trì tương tự như phiên bản máy tính.
  • Nếu gặp lỗi không hiển thị hoặc phản hồi chậm, hãy thử tải lại trang hoặc tắt/bật lại extension trong menu Orion.
